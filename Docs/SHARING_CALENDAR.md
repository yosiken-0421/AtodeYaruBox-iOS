# 共有とアプリ内カレンダー（0.2.0）

2026年10月13日：版0.2.0(2)を本人向けTestFlightへ配布しました。全106件のUnit/UI Test、Debug、Release Simulator、iPhoneOS Release Archive、署名・Appleの処理完了を確認済みです。追加料金0円。iPhoneではTestFlight→「あとでやる箱」→「更新」→「開く」で使えます。

カレンダーは「今日」→「カレンダーで見る」から開きます。日付を押すと、その日の項目を時刻順に表示します。「この日に追加」で同じ日付の新しい項目を作れます。前月・翌月へ移動でき、「今日」で戻れます。完了した項目を表示する切替もあります。文字を特に大きくした場合は、日付の一覧から選べます。

共有は項目の詳細→「誰かと共有」から開きます。メモとWebページのURLは最初は含めません。含めたい内容だけを押して選び、「相手に渡す内容」で確認します。「文章で共有」は相手がアプリを使っていなくても読めます。「箱に取り込めるファイルで共有」は、同じアプリを使う相手が内容を確認して、自分の箱へ保存できます。iPhoneの共有画面で、送信先やコピーを選びます。

共有は相手へのコピーです。変更や完了状態を互いに同期する共同編集機能はありません。写真・添付ファイル・OCR原文・保存パス・通知設定は共有ファイルに含めません。受け取ったファイルは保存する前に確認できます。新しい権限やアカウント登録は不要です。アプリ内カレンダーは箱の項目を表示し、iPhoneの外部カレンダーを読みません。
